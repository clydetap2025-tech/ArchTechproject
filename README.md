# DayTrace

Личный дневник, который превращает один день — текст, фото и песню — в живую страницу-воспоминание: 30 секунд под фрагмент песни, с палитрой из ваших снимков, светом и художественной техникой из слов записи, ритмом и движением из музыки. Каждый день ложится в папку с названием, которое система придумывает сама.

Кейс ArtTech «Make the Invisible Visible», 19–22 ноября 2026.

## Как запустить

Для просмотра нужен современный браузер. Личные архивы обслуживает PocketBase. На Windows x64 скрипт запускает сайт и сервер аккаунтов.

**Windows x64**

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Откройте <http://localhost:8080>. При первом запуске скрипт скачает PocketBase 0.40.6 с GitHub и проверит SHA-256. Сервер слушает только 127.0.0.1:8090. Учётные записи, оригиналы фото и остальные файлы сохраняются в `%LOCALAPPDATA%\PogodaVnutri\data` между перезапусками.

Нажмите «Войти» → «Создать аккаунт». После регистрации добавьте день и фотографии. В записи откройте «Ещё» → «Фотографии дня», чтобы скачать оригинал снимка. Демо можно открыть без входа. Если на устройстве есть записи, созданные до появления аккаунтов, нажмите аватар в шапке и выберите «Перенести прежние записи». Старые записи содержат снимки в качестве, в котором их сохранила прежняя версия дневника.

### Публикация на Vercel

1. Разверните PocketBase 0.40.6 на сервере с **постоянным диском** и HTTPS. Положите каталоги `pb_migrations` и `pb_hooks` рядом с исполняемым файлом или соберите `Dockerfile.pocketbase`. При запуске `./pocketbase serve --dir=/data/pogoda --migrationsDir=./pb_migrations --hooksDir=./pb_hooks` сервер применит схему, правила доступа и маршруты приглашений. Подключите HTTPS через обратный прокси к этому процессу. Настройте резервное копирование каталога данных. [Инструкция PocketBase](https://pocketbase.io/docs/going-to-production/)
2. В проекте Vercel укажите Framework Preset **Other**, добавьте переменную окружения `POCKETBASE_URL` со значением HTTPS-адреса этого сервера. Это публичный адрес, доступный браузерам пользователей. Если используете ограничение `--origins` в PocketBase, разрешите домен фронтенда.
3. Запустите деплой. Параметры сборки берутся из `vercel.json`. Для проверки зарегистрируйтесь, добавьте два снимка и снова войдите в приватном окне. Оба снимка должны открываться в альбоме.

### Друзья и видимость

Сначала обновите PocketBase с обоими каталогами, затем фронтенд. При запуске миграция оставит старые записи приватными. Для новой записи по умолчанию друзьям доступен отпечаток дня. Его можно заменить полной записью или скрыть через «Кто видит день». Проекция обновляется одной транзакцией с записью. Погода в ней содержит состояние и температуру.

Для ручной проверки откройте два тестовых аккаунта в отдельных профилях браузера.

1. A открывает «Аккаунт → Друзья → Пригласить друга». B открывает ссылку, входит и принимает приглашение. Имена появляются у обоих.
2. A сохраняет день как «Только я». B открывает «Атмосфера друзей». После смены на «Друзья видят атмосферу» у B появляются палитра, темп, настроение и погода.
3. A включает «Друзья видят день целиком». B открывает запись, включает музыку и переворачивает обложку.
4. B отправляет тепло с карточки. A снова открывает свой день и переворачивает обложку, чтобы увидеть блок «От друзей».

Проверка серверных правил запускается командой `node tests/friends.mjs`. Перед запуском задайте `POCKETBASE_BIN` абсолютным путём к PocketBase 0.40.6. Скрипт использует отдельную временную базу и проверяет старые записи, одноразовые приглашения, доступ по ID и файловым токенам, отправку тепла и отзыв доступа.

### Демо за 1 минуту

1. Нажмите «Загрузить демо». В семи записях — 27 локальных фото. Карточки галереи можно листать стрелками или свайпом, а снимки каждой записи открываются в фотоальбоме.
2. Откройте любой день → «▶ Слушать день». Нажмите на страницу: она перевернётся, и на обороте будет видно, почему день выглядит именно так.
3. Откройте «Ещё» → «Оформление» и передвиньте точку. Обложка обновится сразу.
4. В меню «Ещё» нажмите «Сохранить папку дня», чтобы создать папку на диске. Без File System Access скачивается ZIP.
5. Листайте развороты архива или найдите день через поиск и фильтры по месяцу, настроению, технике и времени суток. В меню «···» кнопка «Материалы для сдачи» скачивает одним ZIP страницы дней и их обороты (1080×1920), ленту и `дни.md` с названиями папок, техниками и песнями.

Для настоящей демонстрации запишите свой любимый день со своими фото и той самой песней.

После добавления фото в блоке «Песня дня» появятся четыре трека. Можно послушать каждый фрагмент и выбрать трек для воспоминания. Если музыкальные поля пустые, дневник возьмёт первый доступный трек из подборки. Подбор учитывает свет, насыщенность, контраст и температуру цветов.

Кнопка «Определить по геолокации» запрашивает разрешение браузера. Главная показывает текущую погоду, а форма записи запрашивает сводку за выбранную дату. Для Open-Meteo координаты округляются до десятых долей градуса и не записываются в дневник. Место прошлой записи можно ввести вручную по названию города. При первом открытии оформление берётся из календарного сезона. Снежная сцена включается при снегопаде или при наличии снега в текущей сводке.

## Что где лежит

| Файл | Что делает |
|---|---|
| `js/text.js`, `js/lexicon.js` | Локальный разбор текста и подбор названия по правилам |
| `js/photo.js` | Палитра (k-means), свет, контраст, цветовая температура, время съёмки из EXIF |
| `js/audio.js` | Собственный аудиоанализ без библиотек: FFT, темп и сетка долей, тональность и лад (Krumhansl–Schmuckler), энергия, тембр, динамика, самый громкий 30-секундный фрагмент |
| `js/music.js` | Ссылки на сервисы, официальные 30-секундные превью (iTunes Search API), описание по жанру как запасной вариант |
| `js/mood.js` | **Визуальная система:** ввод → координаты настроения → смесь 6 техник → параметры стиля + объяснение «почему так» |
| `js/page.js` | Страница 1080×1920 из фотографий. Кадрирование, раскладка, текст и переходы по долям |
| `js/sound.js` | Воспроизведение фрагмента, живые уровни для анимации, процедурный звуковой фон (дождь, листья, море, офис…), эскиз по описанию песни |
| `js/voice.js` | Озвучка записи синтезом речи: голос, темп и высота по правилам |
| `js/folder.js` | Папка дня на диске или ZIP |
| `js/account.js`, `js/cloud-days.js`, `pb_migrations/` | Вход по почте и паролю, серверные записи и защищённые файлы владельца |
| `js/store.js` | Выбор хранилища, демо в IndexedDB и перенос прежних записей |
| `js/demo.js`, `demo/photos/` | 7 демо-дней и 27 снимков с Unsplash |
| `js/gallery.js`, `js/weather.js` | Галерея, сезонные сцены и Open-Meteo по координатам или городу |

Правила визуальной системы и художественные приёмы описаны в [SYSTEM.md](SYSTEM.md).

## Использованные инструменты

- Веб-платформа: Canvas 2D, Web Audio API, MediaRecorder, File System Access API, IndexedDB, Web Speech API (`speechSynthesis`).
- [iTunes Search API](https://performance-partners.apple.com/search-api): поиск песни и официальные 30-секундные превью. Песни не хранятся, только ссылка и их «отпечаток».
- Подборка по фото использует лицензированные фрагменты из каталога [Incompetech](https://incompetech.com/music/royalty-free/music.html). [Авторы, оригиналы и лицензия](demo/music/CREDITS.md). Если фрагменты подборки недоступны, автоматический поиск использует [Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Audio_files_of_music).
- [Open-Meteo](https://open-meteo.com): текущая и архивная погода, по желанию пользователя.
- oEmbed YouTube и Spotify: название трека по ссылке.
- В архиве используется локальный [Inter](https://rsms.me/inter/) с кириллицей. Обложки и остальные экраны используют системный шрифт.
- Фото демо-дней и сезонных сцен — [Unsplash](https://unsplash.com/license), авторы перечислены в [demo/photos/CREDITS.md](demo/photos/CREDITS.md).
- Видео для фонов главной страницы — [Pexels](https://www.pexels.com/license/). [Авторы и оригиналы клипов](demo/scenery/CREDITS.md).
- Алгоритмы, реализованные вручную: БПФ, автокорреляционный темп, профили тональности Krumhansl–Schmuckler, k-means, ZIP-архиватор, EXIF-парсер.

## Этика и права

- Демо-фото взяты с Unsplash по их лицензии, узнаваемых людей на них нет, авторы указаны. Для главного дня демонстрации используйте свои снимки.
- Музыка: только ссылки и официальные превью. В экспортируемые видео для сдачи лучше ставить треки со свободной лицензией.
- Озвучка — синтезированные голоса браузера, чужие голоса не копируются.
- Система описывает настроение *записи* и не ставит диагнозов. Пользователь может исправить её прочтение.
