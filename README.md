# Погода внутри

Личный дневник, который превращает один день — текст, фото и песню — в живую страницу-воспоминание: 30 секунд под фрагмент песни, с палитрой из ваших снимков, светом и художественной техникой из слов записи, ритмом и движением из музыки. Каждый день ложится в папку с названием, которое система придумывает сама.

Кейс ArtTech «Make the Invisible Visible», 19–22 ноября 2026.

## Как запустить

Нужен только свежий Chrome или Edge (WebGL2, Web Audio, File System Access). Сборки нет, зависимостей нет.

**Windows (без установки чего-либо):**

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Откройте <http://localhost:8080>.

**Любой другой статический сервер тоже подойдёт:** `npx serve .`, `python -m http.server 8080`, GitHub Pages, Netlify, Vercel. Это обычная статическая папка.

**Онлайн на Vercel:** импортируйте этот репозиторий на <https://vercel.com/new>, Framework Preset — **Other**, Build Command и Output Directory оставьте пустыми. Каждый `git push` в `main` обновляет сайт сам. `vercel.json` только кеширует демо-фото, `.vercelignore` не выкладывает локальный сервер.

### Демо за 1 минуту

1. На пустом дневнике нажмите «Показать на 7 демо-днях». Система возьмёт фото из `demo/photos`, найдёт песни, послушает их и соберёт 7 страниц (около 30 секунд). Если запустить без сети или без этих файлов, вместо фото будут нарисованные кодом заглушки тех же сцен.
2. Откройте любой день → «▶ Слушать день». Нажмите на страницу: она перевернётся, и на обороте будет видно, почему день выглядит именно так.
3. Передвиньте точку в блоке «Поправить настроение»: страница перерисуется вживую.
4. «Сохранить папку дня» создаёт настоящую папку на диске. Без File System Access скачивается ZIP.
5. В архиве можно отфильтровать дни по технике и времени суток. Кнопка «Материалы для сдачи» скачивает одним ZIP: страницу и оборот каждого дня (1080×1920), ленту всех дней одной картинкой и `дни.md` с названиями папок, техниками и песнями.

Для настоящей демонстрации запишите свой любимый день со своими фото и той самой песней.

### Необязательно: Claude

В настройках (шестерёнка) можно указать свой ключ Claude API. Тогда модель уточняет настроение, название, подпись и детали записи (по желанию и по фото). Её ответ всё равно проходит через правила системы: проверяется длина названия, подпись и заметки должны быть дословными цитатами. Без ключа всё работает на локальных правилах. Ключ хранится только в этом браузере.

## Что где лежит

| Файл | Что делает |
|---|---|
| `js/text.js`, `js/lexicon.js` | Чтение записи: оси настроения, время суток, сезон, место, люди, события, сенсорные детали, название папки по правилам; опционально Claude |
| `js/photo.js` | Палитра (k-means), свет, контраст, цветовая температура, время съёмки из EXIF |
| `js/audio.js` | Собственный аудиоанализ без библиотек: FFT, темп и сетка долей, тональность и лад (Krumhansl–Schmuckler), энергия, тембр, динамика, самый громкий 30-секундный фрагмент |
| `js/music.js` | Ссылки на сервисы, официальные 30-секундные превью (iTunes Search API), описание по жанру как запасной вариант |
| `js/mood.js` | **Визуальная система:** ввод → координаты настроения → смесь 6 техник → параметры стиля + объяснение «почему так» |
| `js/gl.js` | WebGL2: мазки (двойной фильтр Кувахары), тушь, контуры, постеризация, градиентная карта палитры, свет из окна, засветки, зерно, переходы |
| `js/page.js` | Страница 1080×1920: постоянные элементы, композиции и декор техник, таймлайн по долям |
| `js/sound.js` | Воспроизведение фрагмента, живые уровни для анимации, процедурный звуковой фон (дождь, листья, море, офис…), эскиз по описанию песни |
| `js/voice.js` | Озвучка записи синтезом речи: голос, темп и высота по правилам |
| `js/folder.js` | Папка дня на диске или ZIP |
| `js/store.js` | Локальное хранение в IndexedDB (ничего не уходит на сервер) |
| `js/demo.js`, `demo/photos/` | 7 демо-дней: фото с Unsplash и нарисованные запасные варианты |

Правила визуальной системы и художественные приёмы описаны в [SYSTEM.md](SYSTEM.md).

## Использованные инструменты

- Веб-платформа: WebGL2, Web Audio API, MediaRecorder, File System Access API, IndexedDB, Web Speech API (`speechSynthesis`).
- [iTunes Search API](https://performance-partners.apple.com/search-api): поиск песни и официальные 30-секундные превью. Песни не хранятся, только ссылка и их «отпечаток».
- [Open-Meteo](https://open-meteo.com): погода дня по городу, по желанию пользователя.
- oEmbed YouTube и Spotify: название трека по ссылке.
- Шрифты Google Fonts (OFL): Literata, Caveat, JetBrains Mono.
- Фото демо-дней — [Unsplash](https://unsplash.com/license), 18 снимков, авторы перечислены в [demo/photos/CREDITS.md](demo/photos/CREDITS.md).
- Claude API (Anthropic), необязательно: уточнение чтения записи со структурированным JSON-ответом.
- Алгоритмы, реализованные вручную: БПФ, автокорреляционный темп, профили тональности Krumhansl–Schmuckler, k-means, фильтр Кувахары, ZIP-архиватор, EXIF-парсер.

## Этика и права

- Демо-фото взяты с Unsplash по их лицензии, узнаваемых людей на них нет, авторы указаны. Для главного дня демонстрации используйте свои снимки.
- Музыка: только ссылки и официальные превью. В экспортируемые видео для сдачи лучше ставить треки со свободной лицензией.
- Озвучка — синтезированные голоса браузера, чужие голоса не копируются.
- Система описывает настроение *записи* и не ставит диагнозов. Пользователь может исправить её прочтение.
